# Save All Tabs – Chrome Extension

Save all open tab URLs to a text file with one click.

## Install (unpacked)

1. Open Chrome and go to `chrome://extensions/`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose the `chrome-tabs` folder.

## Use

1. Click the extension icon in the toolbar.
2. Click **Save tabs to file**.
3. Choose where to save the file (or use the default Downloads folder).
4. The file will be named like `tabs-20250216143022.txt` and contain one URL per line.

Chrome internal pages (e.g. `chrome://`) are not included in the file.
